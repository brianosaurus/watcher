Uncle HQ

The headquarters and home of Uncle.

AI coding agents build the software. Uncle makes them prove their work.

Uncle is an open-source (MIT), terminal-native development system that orchestrates Claude, Codex, local models, and other coding agents.

Describe an application or give Uncle a GitHub issue. It plans, implements, independently reviews, verifies, and prepares a pull request, with portable evidence tying the result to the code that was actually reviewed.

Quick start

macOS / Linux / WSL:

curl -fsSL https://raw.githubusercontent.com/unclehq/uncle/main/install.sh -o install.sh && bash install.sh
uncle --application 'build a groovy 1970s themed calculator react webapp with keyboard support' --attended

You need at least one supported AI client installed and authenticated. See the README for prerequisites and Windows instructions.

What makes Uncle different?

  • Independent review. The agent implementing a change cannot approve its own implementation.
  • Artifact identity. The change is the unit of trust: review, verification, approval and publication are tied to the relevant Git tree.
  • Verifiable change provenance. Machine-readable evidence and portable attestations using established standards (in-toto, DSSE).
  • Model flexibility. Use different supported runners and models for implementation, review and other stages.
  • Local-first operation. Uncle runs on your machine in a terminal UI, with no Uncle-hosted backend, account or telemetry.
